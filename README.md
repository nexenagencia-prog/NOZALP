# NOZA LP

Landing page responsiva para a NOZA, construída como site estático e pronta para deploy na Vercel.

## Rodar localmente

Abra `index.html` no navegador ou sirva a pasta com qualquer servidor estático. Não há dependências de build.

## Interações

- Navegação por âncoras e menu recolhível no celular.
- Animações de entrada respeitando a preferência de movimento reduzido.
- Formulário de demonstração com validação de campos.

O envio do formulário está em modo de demonstração e não envia dados a um serviço externo. Para receber leads, conecte-o ao canal de atendimento escolhido.
